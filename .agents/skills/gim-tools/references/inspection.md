# gim-tools reference: inspection

Per-group verb reference for the gim-tools skill.
Generated by `gim-verbs --gen-refs`; deterministic, do not hand-edit.

## gim-inspect

Signature: `gim-inspect [--eof-newline] [--tabs] [--line-endings] [--lines] [--bytes] [--encoding] [--bom] [--trailing-ws] [--max-line-len] [--binary] [--kind] [--mtime] [--hash] [--json]`

Byte-level file checks; missing paths report kind=missing, never error.

| Flag | Detail |
| --- | --- |
| `<path...>` | Paths (positional or pipeline). Missing paths report kind=missing, never error; directories report kind=directory. |
| `--eof-newline` | Report whether the file ends with a newline (eofNewline). |
| `--tabs` | Report whether the file contains tabs (tabs). |
| `--line-endings` | Report the dominant ending: none\|crlf\|lf\|cr\|mixed (lineEndings). |
| `--lines` | Report the line count (lines). |
| `--bytes` | Report the byte length (bytes). |
| `--encoding` | Report BOM-derived encoding: utf-8\|utf-8-bom\|utf-16le\|utf-16be (encoding). |
| `--bom` | Report whether a BOM is present (bom). |
| `--trailing-ws` | Report trailing spaces/tabs on any line (trailingWs). |
| `--max-line-len` | Report the longest line length (maxLineLen). |
| `--binary` | Report whether NUL bytes are present (binary). |
| `--kind` | Report kind=file\|directory\|missing (always included regardless of flags). |
| `--mtime` | Report LastWriteTime (mtime). |
| `--hash` | Report the SHA256 hex of the file bytes (hash). |
| `--json` | Emit { count, truncated, items }. |

## gim-head

Signature: `gim-head -n N [--skip N] [--last] [--json]`

First/last lines of files or a piped text stream; replaces Select-Object -First/-Skip/-Last.

| Flag | Detail |
| --- | --- |
| `-n N` | Number of lines (default 10). |
| `--skip N` | Skip the first N lines before the head window (per file, or across a piped stream). |
| `--last` | Emit the final N lines instead (tail); --skip does not apply. |
| `--json` | Emit { count, truncated, items } of { path, line, text }. |

## gim-count

Signature: `gim-count [--by <field>] [--json]`

Count pipeline items; --by groups counts per record field; replaces Group-Object + count loops.

| Flag | Detail |
| --- | --- |
| `--by <field>` | Group counts per record field value (bare strings group by themselves). |
| `--json` | Emit { count, truncated, items } of { group, count } (or { count } without --by). |

## gim-diff

Signature: `gim-diff --against <glob|path>... | --against-var <name> [--json]`

Two-set path comparison; state in only-left|only-right|both; no intermediate variables.

| Flag | Detail |
| --- | --- |
| `<path...>` | Left set paths (positional or pipeline, e.g. gim-list output); accepts the 'path: ...' record form. |
| `--against <glob\|path>` | Right set: a glob or contained literal path; repeatable. |
| `--against-var <name>` | Right set from a stored newline-separated path list (TTL-enforced, containment-revalidated); accepts the 'path: ...' record form. |
| `--json` | Emit { count, truncated, items } of { path, state }. |

## gim-json

Signature: `gim-json --path <query> [--keys] [--validate] [--json]`

Query JSON documents with a dotted/bracket path; replaces Select-Object -ExpandProperty.

| Flag | Detail |
| --- | --- |
| `<path...>` | JSON file paths (positional or pipeline); YAML/TOML inputs error as unsupported format. |
| `--path <query>` | Dotted/bracket query (a.b[0].c); without it the whole document is the node. |
| `--keys` | List keys (property names or array indices) at the queried node. |
| `--validate` | Check the document parses; report { path, valid } instead of querying. |
| `--json` | Emit { count, truncated, items } of { path, value } (or key strings with --keys). |
