## gim-asm

Signature: `gim-asm types --package <id>/<ver> | --path <dll> [--matches <re>] [--json]`

Enumerate exported type full names via PE metadata; never loads the assembly.

| Flag | Detail |
| --- | --- |
| `types` | Mode (required). |
| `--package <id>/<ver>` | Resolve the package under the nuget read-extra root and pick the best-TFM lib/ dlls. |
| `--path <dll>` | Read one assembly directly (containment includes the nuget read-extra root). |
| `--matches <re>` | Filter type full names by regex. |
| `--json` | Emit { count, truncated, items } of { path, type }. |
