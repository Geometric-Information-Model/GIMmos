# gim-tools reference: state

Per-group verb reference for the gim-tools skill.
Generated by `gim-verbs --gen-refs`; deterministic, do not hand-edit.

## gim-set

Signature: `gim-set <name> [--clear <name>] [--clear-all] [--ttl <sec>] [--json]`

Tee: store the incoming stream in the variable store and pass it through.

| Flag | Detail |
| --- | --- |
| `<name>` | Variable name matching ^[A-Za-z0-9_-]{1,64}$. |
| `--clear <name>` | Remove one variable instead of storing. |
| `--clear-all` | Remove every variable in the namespace. |
| `--ttl <sec>` | Lifetime from last write (default 1 hour; 0 = never expires; negative rejected). |
| `--json` | Store without passing through; emit { name, ttl, stored_bytes }. |

## gim-get

Signature: `gim-get <name> [--max-age <sec>] [--json]`

Read a stored variable (head-only pipeline source); TTL checked on read, never stale.

| Flag | Detail |
| --- | --- |
| `<name>` | Variable name to read. |
| `--max-age <sec>` | Demand the value be at most this old. |
| `--json` | Emit { name, value, age_seconds, ttl_seconds, expired }. |
