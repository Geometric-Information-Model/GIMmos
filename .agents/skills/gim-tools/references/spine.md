# gim-tools reference: spine

Per-group verb reference for the gim-tools skill.
Generated by `gim-verbs --gen-refs`; deterministic, do not hand-edit.

## gim-list

Signature: `gim-list <path...> [--from-file <f>] [--glob <p>]... [--under <d>] [--depth N] [--dirs-only] [--allow-missing] [--print0] [--json]`

List contained paths; sole path entry point (globs, depth, --allow-missing).

| Flag | Detail |
| --- | --- |
| `<path...>` | Literal paths; each is real-path resolved and asserted contained in roots.json. A missing path errors unless --allow-missing. |
| `--from-file <f>` | Read literal paths from a contained file, one per line. |
| `--glob <p>` | Glob relative to each configured root; ** crosses directory separators, * does not. Repeatable. A glob that matches nothing errors unless --allow-missing. |
| `--under <d>` | Re-root the listing at a contained directory; emits items strictly below it. |
| `--depth N` | Recursion depth; 1 = immediate children (relative to the glob anchor directory for globs). |
| `--dirs-only` | Keep only directory paths. |
| `--allow-missing` | Forgive missing literal paths and empty globs (containment is never forgiven). |
| `--print0` | NUL-separated output; the truncation marker goes to stderr so the NUL token stream stays clean. |
| `--json` | Emit { count, truncated, items }. |

## gim-where

Signature: `gim-where [--exists|--missing|--empty|--non-empty|--matches <re>|--not-matches <re>|--larger-than <n>|--smaller-than <n>|--newer-than <iso>|--older-than <iso>|--ext <e>|--is-file|--is-dir] [--field <name>] [--json]`

Filter a pipeline stream; predicates hit the item (path) or a named record field (works downstream of gim-grep).

| Flag | Detail |
| --- | --- |
| `--exists` | Keep items whose path exists. |
| `--missing` | Keep items whose path does not exist. |
| `--empty` | Keep empty files/directories (or empty strings). |
| `--non-empty` | Keep non-empty files/directories (or non-empty strings). |
| `--matches <re>` | Keep items whose value matches the regex. |
| `--not-matches <re>` | Keep items whose value does not match the regex. |
| `--larger-than <n>` | Keep existing files larger than n bytes (or a numeric field value with --field). |
| `--smaller-than <n>` | Keep existing files smaller than n bytes (or a numeric field value with --field). |
| `--newer-than <iso>` | Keep files last written after the timestamp. |
| `--older-than <iso>` | Keep files last written before the timestamp. |
| `--ext <e>` | Keep files with the extension (with or without the leading dot). |
| `--is-file` | Keep items that are files. |
| `--is-dir` | Keep items that are directories. |
| `--field <name>` | Test a named record field instead of the item (e.g. gim-grep --json downstream). |
| `--json` | Emit { count, truncated, items }. |

## gim-report

Signature: `gim-report [--prefix <label>] [--prefix-each] [--sort <field>] [--format lines|table|json] [--only-failures] [--json]`

Shape/aggregate a stream; --sort replaces Sort-Object, --prefix replaces label loops.

| Flag | Detail |
| --- | --- |
| `--prefix <label>` | Prefix every emitted line with '<label>: ' (lines format; table output needs --prefix-each to carry the label). |
| `--prefix-each` | Explicit per-item prefix form; additionally carries the label into table/json structured output. |
| `--sort <field>` | Sort strings lexicographically or records by property; bare --sort sorts strings (needs a field for records). |
| `--format lines\|table\|json` | Output shape (default lines). |
| `--only-failures` | Keep failing strings/records (fail\|error\|warn, failed=true, or status not ok/pass/success). |
| `--json` | Same as --format json. |
