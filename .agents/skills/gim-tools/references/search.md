## gim-grep

Signature: `gim-grep --pattern <re> [--capture N] [--stdin] [--fixed] [--ignore-case] [--files-only] [--files-without-match] [--count] [--context N] [--max-hits N] [--json]`

Pattern search over paths or a --stdin text stream; default output file:line: text.

| Flag | Detail |
| --- | --- |
| `--pattern <re>` | Required. Regex to match (--fixed escapes it). |
| `--capture N` | Emit capture group N instead of the line (feeds path predicates downstream). |
| `--stdin` | Read a piped text stream instead of paths. |
| `--fixed` | Treat the pattern as literal text. |
| `--ignore-case` | Match case-insensitively. |
| `--files-only` | Emit matching file paths only (no lines). |
| `--files-without-match` | Emit files that lack the pattern. |
| `--count` | Emit per-file match counts. |
| `--context N` | Include N lines around each match (context records, never matches). |
| `--max-hits N` | Cap matching records (default 500). |
| `--json` | Emit { count, truncated, items }. |
