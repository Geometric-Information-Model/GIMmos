# gim-tools reference: mutating

Per-group verb reference for the gim-tools skill.
Generated by `gim-verbs --gen-refs`; deterministic, do not hand-edit.

## gim-fix

Signature: `gim-fix <eof-newline|line-endings|trailing-ws> [--to lf|crlf] [--dry-run] [--json]`

Fix byte-level issues in place; pairs with gim-inspect flags; encoding-preserving.

| Flag | Detail |
| --- | --- |
| `<mode>` | eof-newline \| line-endings \| trailing-ws (pairs with the gim-inspect flags). |
| `<path...>` | Files (positional/pipeline) or the text record lines emitted by gim-inspect through gim-where (path: ... form). |
| `--to lf\|crlf` | Target line ending for eof-newline/line-endings (default: match the file for eof-newline, lf for line-endings). |
| `--dry-run` | Compute the report and write nothing. |
| `--json` | Emit { count, truncated, items } of { path, mode, before, after, changed }. |

## gim-write

Signature: `gim-write --path <p> [--from-stdin] [--create-only] [--encoding utf8|utf8bom|utf16] [--out-dir <d>] [--path-from-var <name>] [--dry-run] [--json]`

Write a pipeline stream to a contained file; default UTF-8 without BOM.

| Flag | Detail |
| --- | --- |
| `--path <p>` | Target path; relative lands under --out-dir, absolute must resolve inside the current repo. |
| `--from-stdin` | Optional when content is piped; required when nothing is piped. |
| `--create-only` | Refuse to overwrite an existing target. |
| `--encoding utf8\|utf8bom\|utf16` | Write encoding (default utf8 = UTF-8 without BOM; PS 5.1 Out-File emits UTF-16). |
| `--out-dir <d>` | Directory for a relative --path (default .agent-scratch/). |
| `--path-from-var <name>` | Read the target path from the variable store (TTL-enforced, containment-revalidated). |
| `--dry-run` | Print the report and write nothing (no directory creation either). |
| `--json` | Emit { count, truncated, items } of { path, existed, created, bytes, encoding, dry_run }. |

## gim-apply

Signature: `gim-apply --create-empty | --touch | --remove [--dry-run] [--json]`

Fixed action vocabulary (--create-empty | --touch | --remove) over a filtered pipeline set; targets may be in the current repo or the OS temp root.

| Flag | Detail |
| --- | --- |
| `--create-empty` | Create an empty file; errors when the target exists. |
| `--touch` | Update LastWriteTime, creating the file when missing. |
| `--remove` | Delete the file; missing is a no-op (changed=False). |
| `<path...>` | Files (positional/pipeline) or the gim-inspect text record lines (path: ... form); directories error for every action. Must resolve inside the current repo or the real OS temp root. |
| `--dry-run` | Report what would change and touch nothing. |
| `--json` | Emit { count, truncated, items } of { path, action, changed }. |
