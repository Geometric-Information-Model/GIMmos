# gim-tools reference: execution

Per-group verb reference for the gim-tools skill.
Generated by `gim-verbs --gen-refs`; deterministic, do not hand-edit.

## gim-run

Signature: `gim-run <build|test|run|publish|ef|format> [--project <p>] [--project-from-var <name>] [--timeout <sec>] [--dry-run] [--json] [-- <args>...]`

Run a dotnet CLI verb on a contained project; env scrub, hard timeout, audit.

| Flag | Detail |
| --- | --- |
| `<verb>` | build \| test \| run \| publish \| ef \| format. |
| `--project <p>` | Project path; relative resolves against the repo root; must be contained in the current repo (exec roots). |
| `--project-from-var <name>` | Read the project path from the variable store (TTL-enforced). |
| `--timeout <sec>` | Hard timeout (default 300s, cap 1800s); on expiry the whole process tree is killed (taskkill /T /F) and the verb exits 124. |
| `--dry-run` | Print the argv and the scrubbed credential env names; run nothing. |
| `--json` | Emit { dry_run, verb, project, argv, scrubbed_env, exit_code, timed_out, stdout, stderr, truncated }. |
| `-- <args>...` | Verbatim trailing dotnet args. PowerShell consumes the first -- itself, so tokens colliding with gim-run flags need a doubled marker (-- -- --json). |

## gim-probe

Signature: `gim-probe --project <p> --route <r> [--method <m>] [--body-file <f>] [--timeout <sec>] [--dry-run] [--json]`

Launch an app on a random local port, poll readiness, issue one HTTP request; always teardown.

| Flag | Detail |
| --- | --- |
| `--project <p>` | Required; project path contained in the current repo (exec roots). |
| `--route <r>` | Required; route to request (e.g. /health). Intended for locally-launched apps on the random port; an absolute http(s) URL is accepted but is outside that local-only design intent. |
| `--method <m>` | HTTP method (default GET; GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS). |
| `--body-file <f>` | Request body file (contained, sent as application/json). |
| `--timeout <sec>` | Readiness timeout (default 300s, cap 1800s); exit 124 on readiness timeout. |
| `--dry-run` | Print the argv and the scrubbed credential env names; launch nothing. |
| `--json` | Emit { project, route, method, port, status_code, body, exit_code, timed_out }. |
