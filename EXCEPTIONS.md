# GIM independent-module additional permission

GIM means Geometric Information Model.

The owner grants an additional permission for independent modules that use
GIM-owned EUPL-covered software.

An independent proprietary module may retain its chosen licence when it uses
documented public GIM APIs, documented assembly boundaries, or documented
process APIs, without copying, embedding, deriving from, or modifying
EUPL-covered GIM source. This permission is generic and non-exhaustive. It can
apply to independent modules such as GimBin, GimCrypt, vendor SDK
adapters, and partner-owned format implementations.

This additional permission broadens, and does not restrict, the rights granted
by the EUPL v1.2. It does not change the EUPL obligations for covered works,
including source and licence obligations when covered works are distributed or
communicated. It does not override any third-party licence terms.

GimBin and GimCrypt are GIM-owned proprietary components outside the EUPL
licence for their source and implementation. The first-party inventory is
maintained in [`PROPRIETARY_COMPONENTS.md`](PROPRIETARY_COMPONENTS.md), but that
inventory does not limit this permission's scope. External vendor plugins are
not GIM-owned inventory.

This permission applies only to independent modules as described above. It
does not exempt code that copies, embeds, derives from, or modifies
EUPL-covered GIM source.
